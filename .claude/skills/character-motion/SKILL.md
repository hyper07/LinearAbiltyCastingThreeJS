# Character motion: dances, emotes, idles, locomotion

The user wants every character to move with variety and quality — dances,
celebrations, emotes, idles, locomotion, sports moves — cheaply and legally.
The study (`knowledge/motion-study.md`) verified the free motion sources, the
three.js pipelines and the plush/chibi rules; `src/shared/motion/` holds the code
and `motion-lab.html` (dev only) the proof.

## 1. Find the knowledge (cheap)

```bash
npm run kb -- dance beat chest pop          # techniques → motion-study sections
npm run kb -- retarget plush chibi
npm run kb -- --show own.shared.motion      # the module's API
npm run kb -- dance --models                # animated models and their clip lists
```

Then read only the section you need of `knowledge/motion-study.md`:
§2 sources and licences (usable / not) · §3 what the library holds · §4 three.js
pipelines (loaders and BVH gotchas, retargeting tools, masks/additive/crossfades,
root motion, compression, baking) · §5 plush/chibi retarget rules · §6 procedural
dance recipes with exact timing · §7 springs, IK, motion matching · §8 learning
from famous dances · §9 generative models and verdicts · §10 what to use for
what · §12 checklist.

## 2. Start from what exists

- `src/shared/motion/dance.js` (pure): `beatClock`, `fitBeatOffset`/`detectOnsets`,
  curves (`pop`, `bounce`, `step`, `wave`), `MOVES` + emotes, `routine`,
  `makeCombo(seed)`, `mirrorPose`, `clampPlushPose`, `spring`, `secondary`,
  `applyPlushPose(rig, pose, { mask, weight })` — on the plush riders' bone names.
- `src/shared/motion/signatures.js` (pure): each plush species' signature dance
  (`SIGNATURES`, 8 bars in 4 variants) and `podiumDance(id, { place, start })` with the
  podium places' flourishes; all seven side by side at `/motion-lab.html?view=crew`.
  Smooth: half-time moves played at exactly 1.5× (`RATE`: three counts to two beats of the song),
  held poses, sine ease, hips→chest→arms→head follow-through (`glide`, `groove`, `swell`, `LAG`
  in dance.js; motion-study §6.3), under 6 rad/s.
- `src/shared/motion/retarget.js`: `aimRetarget` (humanoid clip → one-bone limbs),
  `bakePoseClip`, `compressClip`, `maskClip`; `clipTools.js` (pure) for keys, masks,
  root motion.
- `src/library/characters.js`: `characterLoader`, `rigClips`, `retargetClip`
  (humanoid → humanoid), `BONE_MAPS`, VRM expressions.
- Clips: Mesh2Motion's 234 human clips (`library/rigged/mesh2motion/human/animations/`,
  CC0), Quaternius UAL in `library/inbox/`, RobotExpressive, `library/extras/motion/pirouette.bvh` (CMU).

## 3. Rules

- **Licences first** (§2). Ship CC0/CC BY/CMU clips with visible credits. Mixamo and
  Rokoko only inside a build, never as raw files in the repo or fetched by script.
  Never ship AIST++, Bandai Namco, Motorica, LaFAN1, SFU, Ready Player Me's library,
  or anything generated by a model trained on AMASS/HumanML3D/AIST++ (prototype only).
- **Plush/chibi**: paws in the visibility envelope (arms up = a V, never straight up);
  rubber-hose reach for waves and points; exaggerate body, head and ears; ears and
  tails on springs; in place.
- **Slow reads as real dancing** (the user's call): to a fast song, move in half time, hold
  poses, flow with sine ease, overlap the joints; no hits on every beat, no hops (one for a
  winner in two bars at most). The user then asked for them 1.5× quicker (still smooth): the
  podium plays the half-time moves at `RATE` 1.5. Keep joints under ~6 rad/s and test it.
- **On the beat**: hits peak on the beat, bounce lowest on the beat, claps on 2 and 4;
  use the manifest's **measured** BPM and a fitted offset.
- **Original choreography**: generic moves in our own order (`makeCombo`), our music;
  never a song's signature routine.
- **Hands off other games' code** unless the task is that game (memory: focus games;
  other sessions edit Kickrani and Snowpuff). Add new movement through
  `src/shared/motion/` and call it from the game.
- Heavy generation (if ever) runs on the Mac Studio over SSH; only clips come back.

## 4. Check the result

Open `/motion-lab.html` with the dev server (or the game), take Playwright
screenshots at a hit and between hits (`?clip=…&t=…&pause=1&focus=N`,
`window.__motionLab.setTime(t)`), look at them, go through motion-study §12.
Then `npm test` and `npm run build`.
